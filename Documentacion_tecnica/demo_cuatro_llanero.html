Catálogo de las 6 Secuencias Gramaticales (Golpes Llaneros)

Haz clic en "▶ Escuchar Golpe" para que el cuatro toque automáticamente cada regla de la gramática con ritmo de joropo, o tócala tú mismo con el teclado.

1. Golpe de Gabán Ataque Rápido

Regla: T → D → D → T → F
Re Mayor → La7 → La7 → Re Mayor → Frenao. Ataque acústico directo.

2. Golpe de Pajarillo Ataque Pesado

Regla: M → S → D → M → F
Si menor → Sol Mayor → La7 → Si menor → Frenao. Joropo recio en tono menor.

3. Seis por Derecho Defensa / Parry

Regla: T → S → D → T → F
Re Mayor → Sol Mayor → La7 → Re Mayor → Frenao. Cadencia clásica brillante.

4. Zumbe y Zumbe Aturdir / Cortar

Regla: S → D → S → D → F
Sol Mayor → La7 → Sol Mayor → La7 → Frenao. Síncopa de tensión que interrumpe al jefe.

5. Tonada de Sabana Curación / Buff

Regla: T → M → S → T → F
Re Mayor → Si menor → Sol Mayor → Re Mayor → Frenao. Progresión melódica suave.

6. Contrapunteo Libre Combo Recursivo

Regla: T → D → (S → D → T)+ → F
Puedes repetir el ciclo (S → D → T) 1, 2, 3 o más veces antes del Frenao para multiplicar el daño.
